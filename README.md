# Personal Development

A static site listing my projects. Plain HTML, CSS and JavaScript, with Alpine.js (from a CDN) for the tag filter. There's no build step.

- **Add or edit a project:** change `projects.js`.
- **Styling:** `styles.css`. Colours are variables at the top, with a dark-mode set.
- **Preview:** open `index.html` in a browser, or run `python3 -m http.server` and go to http://localhost:8000.
- **Deploy:** upload these files to any static host (GitHub Pages, Netlify, Cloudflare Pages).
